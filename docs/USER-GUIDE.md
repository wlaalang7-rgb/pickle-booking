# PickleRally User Guide

This guide explains how to check court availability, request a booking, and cancel a request on the PickleRally website.

## 1. Explore the website

- **Courts** shows the courts and their current hourly day and night rates.
- **Availability** shows a public calendar and hourly court status. Use the month arrows, then select a date to review its details. Customer names and contact details are not shown.
- **The club** includes photos, community information, events, and membership enquiries.
- **Visit us** lists the venue and published hours. Hours may change on holidays; check with the club before travelling.

The public schedule may include sample open-play and maintenance labels. These examples are informational; use the booking form and its current availability options when choosing a slot.

## 2. Submit a court request

1. Select **Book a court** or go to the booking form.
2. Enter your name and a valid email address.
3. Select one or more courts. Multiple courts in one request use the same date, start time, and duration.
4. Choose the number of players (2–4), a duration (1–3 hours), and a date.
5. Choose an available time. Booking options run from 7:00 AM to 10:00 PM, subject to availability and court closures. Day rates apply to bookings starting before 5:00 PM; night rates apply to bookings starting at or after 5:00 PM. The selected rate applies for the full duration.
6. Optionally enter a promo code and notes. Promo eligibility requires a valid email address; a code can be used once per email address. The estimate updates when the code is verified.
7. Review the estimated total and select **Send booking inquiry**.

The displayed total is an estimate, not a payment or receipt. The website does not collect payment. A request remains **pending** until the club confirms it; submitting the form does not reserve a confirmed slot. Contact the club if you need to check its status.

## 3. Find your reference and cancellation link

After a successful submission, the page displays a booking reference. A booking email should also contain the reference, requested court details, and a secure cancellation link valid for 48 hours.

- If the page says the request was saved but the email could not be sent, keep the on-screen reference and contact the club. Do not submit the form again just to retry the email.
- If the connection is interrupted and the page cannot confirm whether the request was saved, contact the club before trying again.
- Check your spam or junk folder if the email does not arrive.

## 4. Cancel a request

You can cancel within 48 hours of submitting the request:

1. Open **Cancel a booking**.
2. Enter the booking reference and the email address used for the request, or open the secure cancellation link from the booking email.
3. Select **Cancel booking** and wait for the success message.

If a request included multiple courts, cancellation applies to the entire request. A successful cancellation changes the request to **cancelled** and makes its court time available again. After 48 hours, use the club's contact options to ask for help; this page will not cancel an expired request.

## 5. Venue and play information

The website lists PickleRally at **SM City Valenzuela** and publishes regular hours of **7:00 AM–10:00 PM**. Holiday hours may vary. Use the website's directions and contact links to confirm current details before visiting.

The site also publishes court etiquette and notes that first-visit paddle rental is available on request. Ask staff to confirm equipment, event dates, membership terms, and other details; website event listings are marked as examples.

## 6. Privacy and troubleshooting

Public availability views do not show player names or contact details. Your name and email are used to process the request and send its reference; optional notes are visible to staff.

| What you see | What to do |
|---|---|
| No courts or rates appear | Refresh the page and try again later. If the problem continues, contact the club. |
| The site says too many booking requests came from this network | Wait and try again later. Other visitors sharing the same network may also count toward the limit. Contact the club if your request is urgent. |
| A preferred slot is unavailable | Choose another time or date. A pending request, confirmed booking, or maintenance/closure block can prevent a new request. |
| A promo code is rejected | Check the spelling, expiry, usage limit, and whether it has already been used with this email. |
| The request was saved, but no email arrived | Keep the on-screen reference, check spam/junk, and contact the club. Avoid creating a duplicate request. |
| Cancellation is unsuccessful | Check the reference and email, use the secure link, and confirm the request is still within the 48-hour cancellation window. Otherwise, contact the club. |
